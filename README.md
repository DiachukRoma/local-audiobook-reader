# Local Audiobook Reader

Локальна читалка аудіокниг для macOS (Apple Silicon). Читає вголос книжки **українською** та **російською** мовами за допомогою нейронного синтезу мовлення, що працює повністю на вашому Mac.

- Без лімітів символів, без підписки, без облікового запису, без платних API.
- Після одноразового завантаження моделі працює **без інтернету**.
- Документи, згенероване аудіо, позиції читання й налаштування нікуди не надсилаються.
- Телеметрії немає.

## Можливості

- Формати: **PDF**, **EPUB**, **TXT**, **DOCX**.
- Відкриття через кнопку «Відкрити файл…», меню «Файл → Нещодавні» або перетягуванням файлу у вікно.
- Автовизначення мови тексту (українська/російська) з можливістю вибрати вручну.
- 10 нейронних голосів (5 жіночих, 5 чоловічих), швидкість 0,70×–3,00×.

  Модель Supertonic 3 погано змінює темп сама: на 1,6–2,0× вона пропускає слова, на 0,7× повторює й плутає їх (перевірено розпізнаванням мовлення). Тому модель завжди говорить у своєму природному темпі, а швидкість змінюється окремо алгоритмом WSOLA без зміни висоти голосу, як у плеєрах подкастів. Так зберігаються всі слова на будь-якій швидкості, а паузи пропорційно коротшають. До 2× мовлення чисте; на 2,5× зрідка зливаються сусідні звуки; на 3× мовлення дуже стиснуте й підходить тим, хто звик до швидкого прослуховування.
- Читати/пауза, стоп, попередній/наступний абзац, повтор абзацу, перехід до будь-якого абзацу (подвійне клацання або повзунок), перехід за змістом (розділи EPUB, заголовки DOCX, закладки PDF).
- Підсвічування абзацу, що читається, і поточного фрагмента в ньому. Розмір шрифту поточного абзацу (нижній блок) змінюється в «Налаштуваннях».
- Запам'ятовування позиції для кожної книжки (працює навіть після перейменування/переміщення файлу).
- Під час запуску автоматично відкривається остання книжка з того місця, де ви зупинилися.
- Для PDF: вибір діапазону сторінок, видалення повторюваних колонтитулів і номерів сторінок, склеювання абзаців на межі сторінок.
- **Розпізнавання тексту (OCR) сканованих PDF** українською та російською: на macOS вбудованим рушієм Apple Vision, на Windows — RapidOCR. Працює офлайн, документ не залишає комп'ютер (див. розділ «Скановані PDF (OCR)»).
- Звук генерується фрагментами у фоновому потоці та відтворюється без пауз, поки готуються наступні фрагменти; інтерфейс не зависає.
- Кеш згенерованого аудіо (FLAC) з обмеженням розміру та кнопкою очищення.
- Експорт розділу або всієї книжки в аудіофайл (M4A/AAC, FLAC або WAV).
- **Біблійні посилання** читаються повністю: «Мт. 5:3» → «Матвія, п'ятий розділ, третій вірш». Є також **власний словник скорочень**.

Гарячі клавіші: **Пробіл** — читати/пауза, **⌘→ / ⌘←** — наступний/попередній абзац, **⌘R** — повторити абзац, **⌘.** — стоп, **⌘O** — відкрити, **⌘,** — налаштування.

## Рушій мовлення: Supertonic 3

Обрано **[Supertonic 3](https://huggingface.co/Supertone/supertonic-3)** від Supertone Inc.:

| Перевірка | Результат |
|---|---|
| Українська | Так — код `uk` в офіційному списку 31 мови моделі та SDK; перевірено реальним синтезом |
| Російська | Так — код `ru`; перевірено реальним синтезом |
| Локальна робота на Apple Silicon | Так — ONNX Runtime на CPU, ≈3–7× швидше за реальний час на M5 Pro |
| Розмір | ≈385 МБ (ONNX-файли + 10 стилів голосу), ≈99 млн параметрів |
| Ліцензія | Модель — OpenRAIL-M (дозволяє особисте використання, з обмеженнями щодо шкідливого використання); код SDK — MIT |
| Без зовнішнього API | Так; модель завантажується з диска в офлайн-режимі (`HF_HUB_OFFLINE=1`) |
| Безпека | Модель — лише ONNX-графи та JSON; жодного виконуваного Python-коду з моделі не завантажується |

Інші кандидати, які розглядалися:

- **Piper** — має окремі голоси `uk_UA` і `ru_RU`, але якість для тривалого читання нижча, а мови потребують різних моделей.
- **Kokoro** — не підтримує українську й російську.
- **Silero TTS** — гарна російська, але моделі завантажуються через `torch.package`, тобто виконують Python-код із завантаженого файлу (суперечить вимогам безпеки), і ліцензія некомерційна.
- **Qwen3 (Ollama)** — це мовна модель, а не синтезатор мовлення. Застосунок **не використовує Ollama**: базове читання від неї не залежить, а переписувати текст книжки за допомогою LLM не потрібно.

### Як перевірялося мовлення

Синтезоване аудіо розпізнавалося локальною моделлю Whisper (окреме тимчасове середовище, не частина застосунку). Результати:

- українська: розпізнано як `uk`, текст збігається («Доброго вечора. Сьогодні ми прочитаємо першу главу книжки. Їжак, ганок, щастя…»);
- російська: розпізнано як `ru`, текст збігається.

Під час перевірки виявилося, що модель **неправильно читає роки цифрами** (наприклад, «1991» звучало як «1198»). Тому перед синтезом числа перетворюються на слова з урахуванням відмінка для років («у 1991 році» → «у тисяча дев'ятсот дев'яносто першому році», «1991 г.» → «тысяча девятьсот девяносто первого года»), а також розгортаються поширені скорочення («і т. д.», «див.», «т. е.» тощо). Це змінює **лише текст, що надсилається синтезатору**, — книжка на екрані не змінюється. Опцію можна вимкнути в налаштуваннях.

## Встановлення

Потрібно: macOS 13+ на Apple Silicon, Python 3.11+ (перевірено з Python 3.14.5).

```bash
cd ~/Documents/local-audiobook-reader
./scripts/setup.sh
```

Скрипт усе встановлює **всередині теки проєкту** (без `sudo` і без змін у системі):

1. створює віртуальне середовище `.venv`;
2. встановлює залежності з `requirements.txt` (версії закріплено; повний список — `requirements.lock.txt`);
3. один раз завантажує модель Supertonic 3 (≈385 МБ) у `models/supertonic-3`;
4. збирає `Local Audiobook Reader.app`.

### Перше завантаження моделі

Модель завантажується з офіційного репозиторію `Supertone/supertonic-3` на Hugging Face, із закріпленою ревізією. Якщо модель відсутня, застосунок покаже про це повідомлення й кнопку «Завантажити модель» — завантаження відбувається лише після вашого підтвердження. Окремо:

```bash
.venv/bin/python scripts/download_model.py
```

## Запуск

- З Finder: двічі клацніть **`Local Audiobook Reader.app`** у теці проєкту (можна перетягнути його в Dock). Також можна обрати книжку у Finder → «Відкрити за допомогою» → Local Audiobook Reader.
- З Термінала: `./run.sh` (або `./run.sh шлях/до/книжки.epub`).
- На Windows (з теки проєкту): ярлик на робочому столі створює `powershell -ExecutionPolicy Bypass -File scripts\create_shortcut.ps1`. Ярлик запускає `run.pyw` без вікна консолі; після переміщення теки проєкту виконайте скрипт ще раз. З Git Bash також працює `./run.sh`.

`.app` — це легкий запускач, який використовує `.venv` проєкту, тому теку проєкту не слід переміщувати (якщо перемістили — запустіть `scripts/build_app.sh` ще раз).

### Як відкрити PDF або EPUB

1. Натисніть «Відкрити файл…» (⌘O) або перетягніть файл у вікно.
2. Мова визначиться автоматично; за потреби оберіть її вручну в полі «Мова».
3. Натисніть «Читати» (або пробіл). Для переходу до розділу клацніть його у списку зліва, до абзацу — двічі клацніть абзац.
4. Для PDF під текстом з'являться поля «Сторінки PDF: з … по …» — вкажіть діапазон і натисніть «Застосувати діапазон».

## Біблійні посилання та словник скорочень

Посилання на Святе Письмо розгортаються під час читання (текст книжки на екрані не змінюється):

| У тексті | Читається |
|---|---|
| Мт. 5:3 | Матвія, п'ятий розділ, третій вірш |
| Мк 1:15 | Марка, перший розділ, п'ятнадцятий вірш |
| 1 Кор. 13:4-7 | Перше Коринтян, тринадцятий розділ, вірші з четвертого по сьомий |
| 2 Тим. 3:16, 17 | Друге Тимофія, третій розділ, вірші шістнадцятий і сімнадцятий |
| Мт. 5–7 | Матвія, розділи з п'ятого по сьомий |
| Пс. 22:1 | Псалом двадцять другий, перший вірш |
| Мф. 5:3 (рос.) | Матфея, пятая глава, третий стих |

- Вбудовано всі книги Старого й Нового Завіту (а також второканонічні) українською та російською, з поширеними варіантами скорочень різних перекладів (Огієнко, Хоменко, Турконяк, Синодальний тощо). Повний перелік: **Файл → Словник скорочень… → «Біблійні книги»**.
- Номер книги («1 Кор.», «II Цар.») читається як «Перше…/Перша…».
- Підтримуються записи «Мт. 5:3», «Мт 5:3», «(Мф. 5, 3)» (з комою, як у православній літературі), «Мт. 5.3», «5:3а», діапазони й переліки («5:3-12, 15; 6:1»).
- Якщо в книжці трапляється скорочення, якого немає у вбудованому переліку, додайте його у «Мої скорочення» з повною назвою книги (наприклад, «Мтф.» → «Матвія»). Після цього посилання «Мтф. 5:3» читатиметься повністю.
- Щоб не зачіпати звичайні слова, посилання розпізнається лише тоді, коли після назви йде номер розділу. Якщо скорочення без крапки, потрібна форма «розділ:вірш»: «Як 5:3» — посилання, а «Як 5 людей» — ні. «Гл.» і «Пр.» (можуть означати «глава», «приклад») розпізнаються лише у формі «розділ:вірш».
- Вимкнути цю функцію можна в «Налаштуваннях».

**Власний словник** (Файл → Словник скорочень… → «Мої скорочення»):
- Додавайте пари «скорочення → як читати» для української, російської або обох мов. Поле «Перевірити» одразу показує, як буде прочитано речення.
- Церковні скорочення часто залежать від відмінка («св. Миколая» → «святого Миколая», «ап. Павло» → «апостол Павло», «ап. Павла» → «апостола Павла»). Тому записуйте їх разом із наступним словом або в потрібній формі.
- Регістр літер має значення.
- За замовчуванням уже додано кілька записів, що не залежать від відмінка: «Св. Письмо», «Св. Писання», «Св. Дух», «Р. Х.», «н. е.» (і російські відповідники).

## Скановані PDF (OCR)

Якщо PDF складається зі сканованих сторінок без текстового шару, застосунок запропонує **розпізнати текст**:

1. Відкрийте PDF як завжди. Для скану з'явиться запитання «Розпізнати текст?», натисніть «Розпізнати».
2. Буде показано прогрес «сторінка N з M». Розпізнавання можна скасувати, а вже розпізнані сторінки збережуться.
3. Далі книжка читається як звичайна.

Меню **Файл → Розпізнати текст (OCR)…** працює для будь-якого відкритого PDF:
- **«Лише сторінки без тексту»** — для змішаних PDF, де частина сторінок є сканами (застосунок повідомить, скільки таких сторінок);
- **«Усі сторінки»** — якщо вбудований текстовий шар PDF пошкоджений або нечитабельний.

Як це працює:
- Сторінки рендеряться в 300 dpi й розпізнаються **Apple Vision** (`VNRecognizeTextRequest`, точний режим, мови `uk-UA` та `ru-RU`). Цей рушій вбудований у macOS і працює повністю на пристрої, без інтернету й без Homebrew. Пріоритет мови береться з поля «Мова».
- На Windows (і Linux) сторінки рендеряться в 200 dpi й розпізнаються **RapidOCR** — моделями PaddleOCR PP-OCRv5 для кирилиці (одна модель для української й російської) на onnxruntime. Моделі (≈18 МБ) лежать у `models/rapidocr/`: `scripts/download_model.py` завантажує їх разом із моделлю мовлення, інсталятор Windows містить їх одразу. Розпізнавання повільніше, ніж Apple Vision: 2–6 с на сторінку.
- Швидкість: ≈0,2–1 с на сторінку; перший запуск рушія після старту застосунку може тривати до півхвилини.
- Розпізнаний текст кешується в `data/ocr-cache/`, тож повторне відкриття книжки миттєве. Застосунок запам'ятовує, що книжку читали з OCR, і позицію читання.
- Типові помилки OCR виправляються автоматично: латинські літери-двійники в кириличних словах (`i`→`і`, `o`→`о`…) замінюються кириличними, сторонні діакритичні символи прибираються.

## Робота офлайн

Після встановлення інтернет не потрібен: модель вантажиться з диска в режимі `HF_HUB_OFFLINE`, телеметрію Hugging Face вимкнено. Це перевірено запуском синтезу в пісочниці macOS із повністю забороненою мережею (`sandbox-exec … (deny network*)`) — обидві мови синтезовано успішно.

Вбудовану телеметрію ONNX Runtime вимкнено (`onnxruntime.disable_telemetry_events()`) перед завантаженням моделі.

Застосунок не запускає жодних серверів і фонових служб. Доступ до мікрофона, «Універсального доступу» чи інших дозволів не потрібен — лише відтворення звуку.

## Відомі обмеження

- **Наголоси та омографи.** Модель іноді ставить неправильний наголос у рідкісних словах чи омографах («за́мок/замо́к»). Це властивість моделі; ручних наголосів інтерфейс не підтримує.
- **Числа.** Роки, відсотки, дроби та порядкові з суфіксами («5-й», «1990-х») розгортаються з відмінком; інші числа читаються в називному відмінку («з 5 книжок» → «з п'ять книжок»). Римські цифри не розгортаються. Без розгортання (опцію вимкнено) модель читає довгі числа ненадійно.
- **Голоси** однакові для обох мов: 10 стилів Supertonic 3 не прив'язані до мови. Окремих «рідних» українських голосів модель не має.
- **OCR** розраховано на друкований текст. Рукописи, дуже низька якість скану, складна верстка (колонки, таблиці, виноски) дають помилки чи неправильний порядок. Короткі рядки з рідкісною пунктуацією іноді втрачають розділові знаки (наприклад «!»» у кінці рядка). Розпізнавання української та російської перевірено на macOS 27 (на старіших версіях набір мов залежить від системи).
- Складні PDF (кілька колонок, виноски, таблиці) можуть мати неідеальний порядок тексту. EPUB із DRM не підтримуються.
- Абзац зі змішаними мовами читається однією обраною мовою.
- Зміна голосу перегенеровує аудіо з поточного фрагмента (1–3 с затримки). Зміна швидкості синтезу не потребує: темп змінюється з уже згенерованого аудіо.
- Синтез виконується на CPU (CoreML не використовується) — цього вистачає з великим запасом.

## Усунення проблем

- **«Модель мовлення ще не завантажена»** — натисніть «Завантажити модель» або виконайте `scripts/download_model.py`. Перевірте теку моделі в налаштуваннях.
- **`.app` не відкривається** — запустіть `./run.sh` у Терміналі, щоб побачити помилку; журнал: `data/launcher.log` і `data/logs/app.log`. Якщо теку переміщено — `scripts/build_app.sh`.
- **Немає звуку** — перевірте пристрій виводу звуку в системних налаштуваннях; змініть його й натисніть «Стоп», потім «Читати».
- **Неправильна мова вимови** — оберіть мову вручну в полі «Мова».
- **Погано розпізнаний скан** — оберіть потрібну мову в полі «Мова», очистіть кеш OCR у налаштуваннях і запустіть «Файл → Розпізнати текст (OCR)…» ще раз. Якщо вбудований текст PDF «кракозябри» — оберіть «Усі сторінки».
- **Фрагмент пропущено** — у рядку стану з'явиться повідомлення; читання продовжиться з наступного фрагмента, позицію не втрачено.
- **Перевірка встановлення** — `.venv/bin/python -m pytest` (124 автоматичні тести, включно з реальним синтезом і реальним OCR обома мовами).

## Збірка інсталяторів (macOS і Windows)

Окрім `.app`-запускача в теці проєкту (`scripts/build_app.sh`), програму можна зібрати як **самодостатній застосунок**: Python, `.venv` і тека проєкту на цільовому комп'ютері не потрібні. Модель мовлення (≈385 МБ) за замовчуванням вбудовується, тож програма працює офлайн одразу після встановлення. Зі збіркою `--no-model` / `-NoModel` інсталятор менший, а модель завантажується під час першого запуску.

Встановлена програма зберігає налаштування, кеш і позиції читання в профілі користувача: `~/Library/Application Support/Local Audiobook Reader` (macOS) або `%LOCALAPPDATA%\Local Audiobook Reader` (Windows).

### macOS (Apple Silicon)

```bash
scripts/build_macos.sh              # з моделлю
scripts/build_macos.sh --no-model   # без моделі
```

Результат у `dist/`: `Local Audiobook Reader.app` та інсталятор `Local-Audiobook-Reader-<версія>-macOS-arm64.dmg` (відкрийте й перетягніть програму в «Програми»). Збірка підписана лише ad-hoc (без Apple ID), тому на іншому Mac під час першого запуску macOS покаже «Apple could not verify… / Не вдалося перевірити». Що зробити:

1. Натисніть **Done / Готово**, а не «Move to Trash».
2. Відкрийте **Системні параметри → Приватність і безпека**, прокрутіть донизу й натисніть **Open Anyway / Усе одно відкрити** навпроти «Local Audiobook Reader».
3. Запустіть програму ще раз і підтвердьте паролем або Touch ID. Це потрібно лише один раз.

Інший спосіб — виконати в Терміналі `xattr -dr com.apple.quarantine "/Applications/Local Audiobook Reader.app"`. У macOS 15+ правий клік → «Відкрити» вже не обходить цю перевірку. Щоб попередження не з'являлося зовсім, потрібні сертифікат Developer ID (платна програма Apple Developer) і нотаризація.

### Windows 10/11 (x64)

Windows-версію можна зібрати лише на Windows: PyInstaller не вміє крос-компіляцію. Є два способи.

**На комп'ютері з Windows.** Потрібні Python 3.11+ з python.org і [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`). У теці проєкту виконайте:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1              # з моделлю
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1 -NoModel     # без моделі
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1 -NoInstaller # лише тека програми, без Setup.exe
```

Результат: `dist\Local-Audiobook-Reader-<версія>-Windows-Setup.exe`. Інсталятор не потребує прав адміністратора. Він створює ярлик у меню «Пуск» (за бажанням і на робочому столі), додає програму в «Відкрити за допомогою» для PDF/EPUB/TXT/DOCX і реєструє деінсталятор у «Програмах і засобах». Інсталятор не підписаний, тому SmartScreen може попередити: «Докладніше» → «Усе одно запустити».

**Через GitHub Actions** (без власного Windows-ПК). Завантажте проєкт у репозиторій GitHub, потім **Actions → Build installers → Run workflow**. Інший спосіб — запушити тег, наприклад `git tag v1.0.0 && git push --tags`. Workflow `.github/workflows/build.yml` збирає на машинах GitHub Windows-інсталятор і macOS `.dmg`. Обидва файли з'являються в артефактах запуску, а для тегів додаються до релізу.

### Що відрізняється у Windows-версії

- **OCR сканованих PDF** виконує RapidOCR замість Apple Vision (див. «Скановані PDF (OCR)»). Він повільніший: 2–6 с на сторінку.
- **Експорт в аудіо** доступний у FLAC і WAV. M4A потребує macOS-утиліти `afconvert`.

## Оновлення

```bash
cd ~/Documents/local-audiobook-reader
.venv/bin/python -m pip install -r requirements.txt   # після зміни версій у requirements.txt
.venv/bin/python -m pytest                           # перевірка
scripts/build_app.sh                                 # перезбирання .app (за потреби)
```

Нова версія моделі завантажується лише свідомо: змініть версію пакета `supertonic` (у ньому закріплено ревізію моделі), видаліть `models/supertonic-3` і запустіть `scripts/download_model.py`.

## Видалення

Усе міститься в теці проєкту. Щоб видалити застосунок, перемістіть у Кошик теку `~/Documents/local-audiobook-reader` (разом із моделлю, кешем і позиціями). Поза цією текою застосунок нічого не створює (якщо ви не вказали в налаштуваннях інші теки для моделі чи кешу). Ollama та її моделі застосунок не змінював.

## Структура проєкту

```
src/audiobook_reader/
  app.py              точка входу
  document/           імпорт PDF/EPUB/TXT/DOCX, OCR (Apple Vision / RapidOCR), нормалізація, мова, поділ на речення
  tts/                абстракція TTSEngine, рушій Supertonic 3, підготовка тексту
  audio/              кеш FLAC, потокове відтворення (sounddevice/PortAudio)
  reader/             контролер читання (фоновий синтез, черга), експорт
  storage/            налаштування й позиції читання
  ui/                 інтерфейс PySide6
tests/                автоматичні тести (синтетичні тексти, без захищених творів)
scripts/              setup.sh, download_model.py, build_app.sh, make_icon.py,
                      build_macos.sh, build_windows.ps1, make_ico.py (збірка інсталяторів)
packaging/            рецепт PyInstaller, скрипт інсталятора Windows (Inno Setup)
.github/workflows/    збірка інсталяторів на GitHub Actions
```

Щоб додати інший рушій синтезу, реалізуйте `TTSEngine` (`tts/base.py`): `voices()` та `synthesize(text, lang, voice, speed)`.
