# Аудіокнижка для iPad (прототип)

Нативний застосунок SwiftUI. Читає TXT і PDF вголос локальною моделлю Supertonic 3 (ONNX Runtime),
скани розпізнає вбудованим Apple Vision. Нічого не надсилається в мережу.

## Збірка

1. Модель має лежати в `../models/supertonic-3` (як для настільної версії: `python scripts/download_model.py`).
   Вона (≈385 МБ) вбудовується в застосунок.
2. Проєкт згенеровано з `project.yml` (XcodeGen, `brew install xcodegen`, далі `xcodegen` у цій теці).
3. Відкрийте `AudiobookReader.xcodeproj`, у Signing & Capabilities виберіть свою команду (Apple ID),
   підключіть iPad (на ньому увімкніть «Режим розробника») і натисніть Run.
   З безкоштовним Apple ID встановлений застосунок працює 7 днів, потім його треба встановити знову.

## Що є
- увесь текст книжки одним полотном; речення, що читається, підсвічено, текст сам прокручується;
  дотик до речення — читати звідти;
- мова (авто / українська / російська), 10 голосів, швидкість 0,7–3× (змінюється одразу, без повторного синтезу);
- числа читаються словами; речення не рвуться на «Т. Шевченко», «р.», «с. 5»;
- скановані PDF: вибір мови й розпізнавання на пристрої, результат кешується;
- фонове відтворення, керування з екрана блокування й навушників; позиція кожної книжки зберігається.

## Чого ще немає (порівняно з настільною версією)
EPUB і DOCX, словник скорочень, біблійні посилання, порядкові числівники й відмінки, прибирання колонтитулів
зі сканів, діапазон сторінок PDF, експорт в аудіо, пошук.

## Перевірка синтезу
Debug-збірка з аргументом запуску `-selftest` синтезує тестові речення й кладе в Documents застосунку
`selftest.json` (токени, тривалість) і WAV-файли — для порівняння з Python SDK.
